# Performance result artifacts

Raw k6 JSON summaries are generated here and ignored by Git. Curated Markdown reports may be committed when the environment and workload are documented.

- `stress-latest.json` — local raw output generated by `npm run load:stress`.
- `STRESS_LATEST.md` — generated human-readable snapshot from the latest stress run.
- `../../docs/performance/BASELINE_v0.6.5.md` — reproducible baseline already measured before the progressive stress profile.
